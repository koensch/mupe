# Most Useless Project Ever!
This project is all about the B&G NETWORK series product i could find. Build a C-coded application that can monitor, write and interact with ACP, PILOT, QUAD, WIND and DATA modules. I threw in a nice web-status page, an API interface (use curl to set/reset variables), and a connectivity with NMEA 2000 and Signal K.

This is history or nautical archeology. Stuff from 1985-2005. Nobody has this stuff on their boat. This is not 'Fastnet', no, it's the precursor of 'Fastnet', the 11000 baud serial bus. Some features might have been carried over to Fastnet, but i am no Fastnet specialist.

This is not my invention, just a gathering of public information packed in a nice executable, verified against some dusted-off pieces of boating instruments that was scraped from ebay and the like for only a few bucks. I don't have the cash to buy the newer stuff to evaluate. So i just leave ith with the NETWORK series equipment.

Work in progress, still finding particularities every day. Do not expect a full-working application yet. This is not a full-time project. I spend about 4-8 hours per week and progress is slow but steady.

My ultimate goal is to allow the PILOT unit to work with PyPilot.

This is what you retire an instrumentation and software specialist with a sailing hobby.

If you are interested, you are free to access the source code.

There is a PDF in the repository where most findings and observations are described, and a little more background about this project.
