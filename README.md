# Most Useless Project Ever!
This project is all about the B&G NETWORK i could find. Build a C-coded application that can monitor, write and interact with ACP, PILOT, QUAD, WIND and DATA modules. I threw in a nice web-status page, an API interface (use curl to set/reset variables), and a connectivity with NMEA 2000 and Signal K.

This is not my invention, just a gathering of public information packed in a nice executable.

Work in progress, look for mupe.pdf for a summary of findings.

My ultimate goal is to allow the PILOT unit to work with PyPilot
